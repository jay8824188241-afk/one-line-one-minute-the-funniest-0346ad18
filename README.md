A tiny deterministic Node program that writes one very funny AI excuse for a missed deadline to `/output/entry.txt`: an agent that hallucinated a later deadline, hit that one instead, and is therefore — technically — early.

## Run it

```sh
node main.ts
```

This writes the one-liner to `/output/entry.txt` (104 characters, UTF-8, no trailing newline).
